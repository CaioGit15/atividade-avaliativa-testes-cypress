# Desafio QA - Cypress

## Como executar (GitHub Codespaces)

```bash
npm install
npm run cy:run        # executa todos os testes (headless)
npm run q1            # executa somente a Questão 1
npm run q2            # executa somente a Questão 2
npm run q3            # executa somente a Questão 3
npm run q4            # executa somente a Questão 4
npm run q5            # executa somente a Questão 5 (gera cypress/results/)
```
